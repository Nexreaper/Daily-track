      Random check-in

      Honest answer, one line.

      Turn on notifications

      One-time unblock — takes about 20 seconds.

      If your browser blocked them

      1. Tap the lock / settings icon to the left of the address bar.
      2. Open Site settings (in Safari: “Settings for this website”).
      3. Set Notifications → Allow.
      4. Reload this page, then hit the test button in Settings.

      On Android

      Also allow Chrome notifications in Android Settings → Apps → Chrome → Notifications. Phones pause background timers, so OS reminders fire while the app is open in a tab.

      If they are already allowed

      OS notifications only fire while the app is open — a single-file app cannot run a background service worker. In-app reminders (toasts and the check-in prompt) always work regardless.
